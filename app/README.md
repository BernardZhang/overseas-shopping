# Everyday Edit

12 mock products: Home, Travel, Desk. English/USD. Browsing, combined search/category/price filtering, stable sorting, details, cart quantity/removal, validated localStorage and responsive layouts. No payment or real orders.

Node >=22.12; Node 24.x recommended. Run npm ci, npm run dev, npm test, npm run build, npm run preview.

Local project SVG illustrations require no external image service. Ratings are simulated. Lucide icons via lucide-react. QA HTML fixtures outside public/ are excluded from the production build.

Vercel: root app, Vite, npm ci, npm run build, dist. No secrets/environment variables. See ../docs/VERIFICATION.md for actual validation.
